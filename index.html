Evolutionary Robotics: Mountain-Climbing Creatures

A PyBullet evolutionary-robotics project using genetically encoded robot morphology and motor control, URDF generation, physics simulation and genetic-algorithm search.

Watch demo highlight View source on GitHub

Mountain-climbing demonstration

The recorded project presentation shows the evolved creature interacting with the mountain terrain in PyBullet. This short highlight is taken from the submitted presentation video.

AI pipeline

1. Encode

Genomes describe link dimensions, joint configuration and motor-controller parameters.

2. Simulate

Genomes are converted into articulated URDF creatures and evaluated in PyBullet.

3. Evolve

Selection, crossover, mutation and elitism search for increasingly effective behaviours.

Recovered project scope

The archive contains the creature genome, URDF generation, procedural motors, population/simulation code, tests and a recovered GA framework with mountain assets. The presentation also shows later terrain-aware Part B experiments and evolutionary learning curves.

Recovery note: the exact standalone final Part B experiment script visible in the recorded presentation was not present in the recovered ZIP. The repository therefore keeps the source and demo evidence separate rather than claiming full reproducibility of every chart.
